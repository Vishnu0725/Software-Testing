# Team of Five — Roles and 4-week plan

## Suggested roles
| Member | Role | Main responsibility |
|---|---|---|
| 1 | Team lead / Test analyst | Scope, test plan, weekly coordination, final report and slides |
| 2 | Functional tester | Scenarios, date/time, seat selection and booking cases |
| 3 | Automation developer | Playwright setup, TypeScript scripts, test execution |
| 4 | Validation / test-data analyst | Boundary tests, calculations, expected results, retest |
| 5 | Evidence / documentation | Defect log, screenshots, HTML report, demo script, formatting |

## Weekly plan
| Week | Work | Output |
|---|---|---|
| 1 | Topic confirmation, AUT, scope, requirement analysis, test plan | Approved test plan and initial scenarios |
| 2 | Detailed cases, setup, test data, framework | Test cases and first automated tests |
| 3 | Script completion, test runs, defect investigation | Test execution evidence and defect log |
| 4 | Regression/retest, results, report, presentation, demo rehearsal | Final report and presentation |

Members should review one another's test cases and scripts; role assignments can be adjusted based on availability.
