## Severity guide
- **Critical:** blocks core booking flow, data integrity/security impact, no workaround.
- **Major:** important functionality broken; workaround may exist.
- **Minor:** limited impact, visual/secondary functionality issue.
- **Trivial:** cosmetic issue with minimal user impact.

## Priority guide
- **P1:** fix immediately before release/demo.
- **P2:** fix in planned release.
- **P3:** fix when time allows.
